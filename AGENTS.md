# Workspace Rules & Agent Instructions

## 1. Pre-Change Git Safeguard (MANDATORY)
- **Notify First**: Before making ANY major changes, restructuring, or new feature implementations, ALWAYS intimate/notify the user first to commit and push all working code to Git.
- **Ensure Clean Working Tree**: Verify all current progress is safely committed and pushed to GitHub before introducing new modifications.
- **No Destructive Commands**: NEVER run blanket rollback commands like `git checkout -- <file>`, `git restore`, or `git reset` on uncommitted workspace files.
