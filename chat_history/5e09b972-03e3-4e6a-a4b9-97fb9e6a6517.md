All your conversation chats in Antigravity are **automatically saved locally**. You do not need to manually hit "Save" after every message. 

Here is how conversation chats are saved, how to access past chats, and how to export them into readable Markdown/text files inside your project.

### 1. Where Antigravity Automatically Stores Your Chats

Every conversation session and its full message history is permanently logged on your local machine at:

```plaintext
C:\Users\ravi.mallem\.gemini\antigravity\brain\
```

Inside that folder, each conversation has its own UUID folder (for example, `5e09b972-03e3-4e6a-a4b9-97fb9e6a6517`), containing:
* **Full Transcript Logs**:
  `...\brain\<conversation-id>\.system_generated\logs\transcript_full.jsonl`
* **Artifacts & Generated Files**:
  `...\brain\<conversation-id>\` (all plans, code artifacts, and notes generated in that session).

* **Reuse in New Conversations**: When starting a new conversation, type `@` in the prompt box and select previous conversations or files to bring their context into the new chat.

### 3. How to Export / Backup All Chats to Your Project Folder

If you want to save all conversations into your project directory (e.g., `d:\OTSi_ESS_Portal\chat_history\`) as human-readable Markdown (`.md`) files, you can use a simple Python script:

#### Quick Python Exporter Script
Create a script (e.g., `export_chats.py` in your project or run it in your terminal):

```python
import json
import os
from pathlib import Path

# Path where Antigravity stores conversation logs
brain_dir = Path(r"C:\Users\ravi.mallem\.gemini\antigravity\brain")

# Target folder in your project where you want chats saved
output_dir = Path(r"d:\OTSi_ESS_Portal\chat_history")
output_dir.mkdir(parents=True, exist_ok=True)

for conv_dir in brain_dir.iterdir():
    if not conv_dir.is_dir():
        continue
    
    transcript_file = conv_dir / ".system_generated" / "logs" / "transcript_full.jsonl"
    if not transcript_file.exists():
        transcript_file = conv_dir / ".system_generated" / "logs" / "transcript.jsonl"
    
    if not transcript_file.exists():
        continue

    md_output = [f"# Conversation {conv_dir.name}\n"]
    
    with open(transcript_file, "r", encoding="utf-8") as f:
        for line in f:
            try:
                item = json.loads(line)
                role = item.get("source", "")
                step_type = item.get("type", "")
                content = item.get("content", "")
                
                if step_type == "USER_INPUT":
                    md_output.append(f"### 👤 User\n\n{content}\n")
                elif step_type == "PLANNER_RESPONSE" and content:
                    md_output.append(f"### 🤖 Assistant\n\n{content}\n")
            except Exception:
                continue

    out_file = output_dir / f"{conv_dir.name}.md"
    with open(out_file, "w", encoding="utf-8") as f:
        f.write("\n---\n".join(md_output))

print(f"Exported conversations to {output_dir}")
```
